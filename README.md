# Google ADK Examples

Sample agents built with the [Agent Development Kit (ADK)](https://adk.dev/).

## Agents

| Agent | Description |
|---|---|
| [`agents/agent-skills`](agents/agent-skills/) | File-based skills + progressive disclosure (Harbor Roast coffee shop demo) |

## Requirements

- Python 3.11+
- [uv](https://docs.astral.sh/uv/)
- [google-agents-cli](https://adk.dev/) — `uv tool install google-agents-cli`

Each agent has its own README with setup instructions.
